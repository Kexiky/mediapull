# MediaPull — Universal Media Downloader

Серверное веб-приложение и Telegram-бот для загрузки, конвертации и обработки медиаконтента (видео, аудио, карусели изображений) с внешних платформ, включая YouTube, Instagram, TikTok, VK Видео, RuTube, X (Twitter), Pinterest и другие.

---

## Архитектура и стек технологий

- **Backend**: Python 3.10+, FastAPI, Uvicorn, yt-dlp, FFmpeg (static-ffmpeg), SQLite (WAL-режим), aiogram 3.x.
- **Frontend**: Vanilla ES6 JavaScript, HTML5, CSS3 (модульная дизайн-система, поддержка тем оформления).
- **Сетевой уровень и парсинг**: requests, curl_cffi (эмуляция браузерных заголовков для обхода ограничений).

---

## Функциональные возможности

### 1. Веб-интерфейс
- **Загрузка видео**: выбор разрешения от 360p до 4K/8K, контейнеры MP4, MKV, WEBM, экспорт в GIF.
- **Извлечение аудио**: конвертация в форматы MP3, M4A, FLAC, WAV, OPUS с автоматическим сохранением метаданных и обложек.
- **Обработка плейлистов**: пакетное скачивание треков и видеороликов, генерация ZIP-архивов.
- **Субтитры**: извлечение встроенных и внешних дорожек в формате WebVTT.
- **Встроенный медиаплеер**: потоковое воспроизведение с поддержкой HTTP Range-запросов (частичный контент, код 206).
- **Очередь задач**: отслеживание прогресса в реальном времени через Server-Sent Events (SSE).

### 2. Telegram-бот
- Автономный сервис на базе aiogram 3.x. Принимает ссылки и возвращает готовые файлы в чат.
- **Кэш `file_id`**: уже отправленное видео/аудио/фото уходит повторно мгновенно (без скачивания), в том числе другим пользователям и через inline-режим.
- **Меню качества с размерами**: примерный вес каждого варианта, пометка «🗜» для тех, что будут пережаты, кнопка «⭐ Авто» (лучшее качество, которое влезает в лимит). Заведомо неподъёмные варианты скрываются.
- **Настройки в БД** (`/settings`): подпись, качество по умолчанию (в т.ч. «без вопросов»), сохранение в веб-библиотеку. Переживают перезапуск.
- **Привязка веб-аккаунта** (`/link КОД`): бот применяет тариф аккаунта (лимит качества, роль), по желанию кладёт файлы в библиотеку сайта.
- **Админ-команды**: `/stats`, `/allow`, `/ban`, `/unban`, `/acl`, `/closed on|off`, `/update`. Администраторы — `TELEGRAM_ADMIN_IDS` и привязанные веб-админы.
- **Группы и inline**: `/dl ссылка` (или ответом на сообщение со ссылкой), упоминание бота; `@бот ссылка` в любом чате.
- **Очередь с позицией и ETA**, один активный запуск на пользователя, лимит запросов.
- **Дополнительно**: `/formats` (форматы и размеры), `/subs` (субтитры файлом SRT), cookies для возрастных/приватных видео (`YTDLP_COOKIES_FILE`).
- **Локальный Bot API** (`docker compose --profile local-api up -d`): лимит файлов 2 ГБ вместо 50 МБ. **Webhook** (`TELEGRAM_WEBHOOK_URL`) вместо long polling.
- Адаптивное сжатие через FFmpeg под лимит Telegram, флаг Faststart для потокового воспроизведения.
- Эфемерное хранилище: каждая задача пишет в собственную папку, которая удаляется целиком сразу после отправки.

### 3. Авторизация и политика хранения данных
- Ролевая модель доступа:
  - **Администратор (создатель)**: бессрочное хранение файлов, отсутствие дисковых квот.
  - **Премиум**: квота 50 ГБ, срок хранения (TTL) 30 дней.
  - **Пользователь**: квота 10 ГБ, срок хранения (TTL) 7 дней.
  - **Гость**: квота 2 ГБ, срок хранения (TTL) 24 часа.
- Автоматический фоновый сборщик мусора (GC) для очистки файлов и превью с истекшим сроком хранения.
- Аутентификация на основе подписанных HMAC-SHA256 токенов с ограниченным сроком действия.

## Установка и подготовка окружения

### 1. Клонирование репозитория
```bash
git clone https://github.com/Kexiky/mediapull.git
cd mediapull
```

### 2. Создание и активация виртуального окружения
- **Windows (PowerShell):**
  ```powershell
  python -m venv .venv
  .venv\Scripts\activate
  ```
- **Linux / macOS:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

## Конфигурация (.env)

Создайте файл `.env` в корневой директории проекта на основе `.env.example`:

```env
# Параметры HTTP-сервера
PORT=8000
HOST=127.0.0.1
MEDIAPULL_WEB_URL=http://127.0.0.1:8000

# Безопасность
# Если секретный ключ не задан, он генерируется автоматически в data/.secret_key
MEDIAPULL_SECRET_KEY=
# Пароль администратора (kexiky) генерируется при первом запуске и выводится в лог;
# сменить его можно командой: python run.py --reset-admin

# Ограничение параллельных загрузок
MAX_CONCURRENT_DOWNLOADS=3

# Настройки CORS (разрешенные источники через запятую)
ALLOWED_ORIGINS=http://127.0.0.1:8000,http://localhost:8000

# Токен Telegram-бота (полученный у @BotFather)
TELEGRAM_BOT_TOKEN=
# Закрытый режим бота: Telegram ID через запятую (пусто = бот открыт для всех)
TELEGRAM_ALLOWED_IDS=
```

### Дополнительные параметры

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MEDIAPULL_TRUST_PROXY` | выкл. | Учитывать `X-Forwarded-For`/`X-Forwarded-Proto` (включайте только за собственным reverse-proxy) |
| `MEDIAPULL_COOKIE_SECURE` | авто | Принудительно ставить флаг `Secure` на cookie (для HTTPS) |
| `MEDIAPULL_ALLOW_PRIVATE_URLS` | выкл. | Разрешить ссылки на локальную сеть (по умолчанию запрещены — защита от SSRF) |
| `MEDIAPULL_MIN_FREE_DISK_GB` | `1` | Не принимать новые загрузки, если на диске меньше свободного места |
| `MEDIAPULL_GUEST_SESSIONS_PER_HOUR` | `60` | Лимит новых гостевых сессий с одного адреса |
| `MEDIAPULL_DATA_DIR` / `MEDIAPULL_DOWNLOADS_DIR` | `data/`, `downloads/` | Расположение базы данных и загрузок |
| `MEDIAPULL_DOWNLOAD_IDLE_TIMEOUT` | `900` | Секунд без вывода yt-dlp до принудительной остановки загрузки |
| `TELEGRAM_MAX_PLAYLIST_ITEMS` | `50` | Максимум элементов плейлиста, отправляемых ботом в чат |
| `TELEGRAM_ADMIN_IDS` | — | Telegram ID администраторов бота (через запятую) |
| `TELEGRAM_BOT_USERNAME` | — | Имя бота без `@`: нужно для упоминаний в группах и подсказки в личном кабинете |
| `TELEGRAM_DEFAULT_ROLE` | `user` | Тариф пользователей без привязанного веб-аккаунта (`user`, `premium`, `guest`) |
| `TELEGRAM_API_SERVER` | — | Адрес локального Bot API сервера, например `http://telegram-bot-api:8081` (лимит файлов 2 ГБ) |
| `TELEGRAM_MAX_UPLOAD_MB` | `48` / `1900` | Максимальный размер отправки (с локальным API по умолчанию 1900) |
| `TELEGRAM_WEBHOOK_URL` / `_SECRET` / `_PORT` | — / — / `8080` | Webhook вместо long polling: публичный HTTPS-адрес, секрет и порт бота |
| `MEDIAPULL_YTDLP_AUTO_UPDATE` | выкл. | Обновлять yt-dlp раз в сутки (`MEDIAPULL_YTDLP_UPDATE_HOURS` — период) |
| `YTDLP_COOKIES_FILE` / `YTDLP_PROXY` | — | Cookies (Netscape) для возрастных/приватных видео; прокси для yt-dlp |

> Если сервис доступен из интернета, поставьте его за reverse-proxy с HTTPS и включите `MEDIAPULL_TRUST_PROXY=true`.

## Запуск сервисов

### Вариант 1. Запуск через Docker Compose (Рекомендуется)

Запуск всех сервисов (веб-интерфейс и Telegram-бот) в изолированных контейнерах:

```bash
docker compose up -d --build
```

- Остановка: `docker compose down`
- Просмотр логов: `docker compose logs -f`
- Логи конкретного сервиса: `docker compose logs -f web` или `docker compose logs -f bot`

### Вариант 2. Локальный запуск

#### Запуск веб-сервера
```bash
python run.py
```
Веб-интерфейс доступен по адресу: **http://127.0.0.1:8000** (или по порту из `.env`).

#### Запуск Telegram-бота
```bash
python run_bot.py
```
Для работы inline-режима включите его у @BotFather (`/setinline`) и укажите `TELEGRAM_BOT_USERNAME`. Чтобы бот видел
сообщения в группах без команд, отключите Group Privacy (`/setprivacy`) или пользуйтесь `/dl` и упоминанием.

#### Сброс пароля администратора (kexiky)
```bash
python run.py --reset-admin
```

#### Тестирование пайплайна бота без авторизации в Telegram
Для проверки работы yt-dlp, FFmpeg и извлечения параметров без отправки сообщений:
```bash
python run_bot.py --test-pipeline "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```

## Структура проекта

```text
mediapull/
├── app/
│   ├── auth.py          # Аутентификация, валидация сессий и токенов
│   ├── bot.py           # Обработчики aiogram, логика сжатия и отправки
│   ├── bot_queue.py     # Очередь заданий бота с позицией и ETA
│   ├── bot_store.py     # БД бота: кэш file_id, настройки, ACL, статистика
│   ├── cleanup.py       # Фоновая очистка файлов по TTL и сборка мусора
│   ├── database.py      # SQLite база данных, пользователи
│   ├── downloader.py    # Менеджер загрузок yt-dlp, FFmpeg-обработка
│   ├── main.py          # FastAPI роуты, стриминг и API
│   ├── ratelimit.py     # Ограничение частоты запросов, определение клиента
│   ├── roles.py         # Роли, квоты и TTL
│   └── updater.py       # Автообновление yt-dlp
├── data/                # База данных SQLite и служебные ключи
├── downloads/           # Директория загруженных файлов пользователей
├── static/              # Статические файлы фронтенда (HTML, CSS, JS)
├── .env.example         # Пример конфигурационного файла
├── requirements.txt     # Зависимости Python
├── requirements-dev.txt # Зависимости для тестов
├── tests/               # Автотесты (pytest)
├── run.py               # Точка входа веб-сервера
└── run_bot.py           # Точка входа Telegram-бота
```
