# ⚡ MediaPull — Universal Media Downloader
> *by Kexiky • Fast • Multiplatform • Permanent Storage*

Современный универсальный медиакомбайн и Telegram-бот для скачивания, умного сжатия и конвертации видео, аудио и каруселей фото с более чем 1000+ платформ (YouTube, TikTok, Instagram, VK, Rutube, Pinterest, X/Twitter и др.).

---

## ✨ Ключевые возможности

- 📥 **Мультиплатформенность (1000+ платформ)**: YouTube, Shorts, Instagram Reels/карусели/фото, TikTok без водяных знаков, VK, Rutube, X/Twitter, Pinterest и др.
- 🎬 **Скачивание видео**: от 360p до 4K/8K, форматы MP4/MKV/WEBM, обрезка фрагментов, субтитры.
- 🎵 **Извлечение аудио**: MP3, M4A, FLAC, WAV с автоматическим вшиванием обложек и ID3-тегов.
- 🤖 **Telegram-бот (aiogram 3.x)**:
  - Мгновенная отправка видео и аудио прямо в чат Telegram в ответ на ссылку.
  - **Умное сжатие под лимит 50 МБ**: автоматический расчёт битрейта через FFmpeg для идеального качества при соблюдении лимита Telegram.
  - Поддержка быстрого стриминга (Faststart) для воспроизведения без задержки.
  - Привязка аккаунта MediaPull через `/auth <токен>`.
- 👑 **Система аккаунтов и ролей**:
  - `kexiky` (Создатель / Админ): бессрочное хранение (без TTL), безлимитное дисковое пространство, наивысший приоритет.
  - Премиум / Пользователь / Гость: настраиваемые квоты и автоматическая очистка по TTL.
- 💾 **Встроенный плеер и менеджер файлов**: просмотр видео, прослушивание аудио, карусели фото, переключение светлой/тёмной тем и цветовых палитр.

---

## 🛠 Технологии

- **Backend**: Python 3.13, FastAPI, Uvicorn, yt-dlp, FFmpeg, SQLite, aiogram 3.x.
- **Frontend**: Vanilla CSS3 (модульные темы, Light/Dark режимы, стекломорфизм), Vanilla ES6 JavaScript.

## 🚀 Запуск веб-приложения

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск веб-сервера
python3 run.py
```
Веб-интерфейс доступен по адресу: **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

---

## 🤖 Запуск Telegram-бота

1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте полученный токен.
2. Укажите токен в файле `.env`:
   ```env
   TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН"
   ```
3. Запустите бота:
   ```bash
   python3 run_bot.py
   ```
   *(Или передайте токен напрямую: `python3 run_bot.py --token "ВАШ_ТОКЕН"`)*

4. **Тестирование пайплайна без токена бота:**
   ```bash
   python3 run_bot.py --test-pipeline "https://www.youtube.com/watch?v=jNQXAC9IVRw"
   ```
