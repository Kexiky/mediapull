# MediaPull — Universal Media Downloader

Серверное веб-приложение и Telegram-бот для загрузки, конвертации и обработки медиаконтента (видео, аудио, карусели изображений) с внешних платформ, включая YouTube, Instagram, TikTok, VK Видео, RuTube, X (Twitter), Pinterest и другие.

---

## Архитектура и стек технологий

- **Backend**: Python 3.11+, FastAPI, Uvicorn, yt-dlp, FFmpeg (static-ffmpeg), SQLite (WAL-режим), aiogram 3.x.
- **Frontend**: Vanilla ES6 JavaScript, HTML5, CSS3 (модульная дизайн-система, поддержка тем оформления).
- **Сетевой уровень и парсинг**: aiohttp, requests, curl_cffi (эмуляция браузерных заголовков для обхода ограничений).

---

## Функциональные возможности

### 1. Веб-интерфейс
- **Загрузка видео**: выбор разрешения от 360p до 4K/8K, контейнеры MP4, MKV, WEBM, экспорт в GIF.
- **Извлечение аудио**: конвертация в форматы MP3, M4A, FLAC, WAV, OPUS с автоматическим сохранением метаданных и обложек.
- **Обработка плейлистов**: пакетное скачивание треков и видеороликов, генерация ZIP-архивов.
- **Субтитры**: извлечение встроенных и внешних дорожек в формате WebVTT.
- **Встроенный медиаплеер**: потоковое воспроизведение с поддержкой HTTP Range-запросов (частичный контент, код 206).
- **Очередь задач**: отслеживание прогресса в реальном времени через Server-Sent Events (SSE).

### 2. Telegram-бот
- Автономный сервис на базе aiogram 3.x.
- Прием прямых ссылок на медиаресурсы и возврат готовых файлов в чат.
- Адаптивное двухпроходное сжатие через FFmpeg для соблюдения лимита Telegram Bot API (50 МБ).
- Поддержка флага Faststart (`movflags +faststart`) для потокового воспроизведения видео в клиенте Telegram без ожидания полной загрузки.
- Эфемерное хранилище: временные файлы удаляются с диска сразу после отправки пользователю.

### 3. Авторизация и политика хранения данных
- Ролевая модель доступа:
  - **Администратор (создатель)**: бессрочное хранение файлов, отсутствие дисковых квот.
  - **Премиум**: квота 50 ГБ, срок хранения (TTL) 30 дней.
  - **Пользователь**: квота 10 ГБ, срок хранения (TTL) 7 дней.
  - **Гость**: квота 2 ГБ, срок хранения (TTL) 24 часа.
- Автоматический фоновый сборщик мусора (GC) для очистки файлов и превью с истекшим сроком хранения.
- Аутентификация на основе подписанных HMAC-SHA256 токенов с ограниченным сроком действия.

## Установка и подготовка окружения

### 1. Клонирование репозитория
```bash
git clone https://github.com/Kexiky/mediapull.git
cd mediapull
```

### 2. Создание и активация виртуального окружения
- **Windows (PowerShell):**
  ```powershell
  python -m venv .venv
  .venv\Scripts\activate
  ```
- **Linux / macOS:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

---

## Конфигурация (.env)

Создайте файл `.env` в корневой директории проекта на основе `.env.example`:

```env
# Параметры HTTP-сервера
PORT=8000
HOST=127.0.0.1
MEDIAPULL_WEB_URL=http://127.0.0.1:8000

# Безопасность
# Если секретный ключ не задан, он генерируется автоматически в data/.secret_key
MEDIAPULL_SECRET_KEY=
# Пароль учетной записи администратора (kexiky)
KEXIKY_PASSWORD=

# Ограничение параллельных загрузок
MAX_CONCURRENT_DOWNLOADS=3

# Настройки CORS (разрешенные источники через запятую)
ALLOWED_ORIGINS=http://127.0.0.1:8000,http://localhost:8000

# Токен Telegram-бота (полученный у @BotFather)
TELEGRAM_BOT_TOKEN=
```

## Запуск сервисов

### Запуск веб-сервера
```bash
python run.py
```
Веб-интерфейс доступен по адресу: **http://127.0.0.1:8000**

### Запуск Telegram-бота
```bash
python run_bot.py
```

### Тестирование пайплайна бота без авторизации в Telegram
Для проверки работы yt-dlp, FFmpeg и извлечения параметров без отправки сообщений:
```bash
python run_bot.py --test-pipeline "https://www.youtube.com/watch?v=jNQXAC9IVRw"
```

## Структура проекта

```text
mediapull/
├── app/
│   ├── auth.py          # Аутентификация, валидация сессий и токенов
│   ├── bot.py           # Обработчики aiogram, логика сжатия и отправки
│   ├── cleanup.py       # Фоновая очистка файлов по TTL и сборка мусора
│   ├── database.py      # SQLite база данных, пользователи и роли
│   ├── downloader.py    # Менеджер загрузок yt-dlp, FFmpeg-обработка
│   └── main.py          # FastAPI роуты, стриминг и API
├── data/                # База данных SQLite и служебные ключи
├── downloads/           # Директория загруженных файлов пользователей
├── static/              # Статические файлы фронтенда (HTML, CSS, JS)
├── .env.example         # Пример конфигурационного файла
├── requirements.txt     # Зависимости Python
├── run.py               # Точка входа веб-сервера
└── run_bot.py           # Точка входа Telegram-бота
```
